PlanoHTML

Oleh: Ceight Ch.

Halo Assalaamu'alaikum Warahmatullahi Wabarakaatuh.

Pada kesempatan kali ini, saya ingin membagikan hasil eksperimen saya dengan AI Deepseek. Dengan tujuan membantu para pekerja seperti percetakan atau semacamnya. Yaitu PlanoHTML.

Sebenarnya eksperimen ini inspirasi dari aplikasi windows Henrywae Plano tahun 2008 yang dibuat khusus untuk pengguna windows. Aplikasi ini untuk menghitung jumlah potongan dengan ukuran tertentu di kertaso dengan ukuran dasar.

Karena aplikasi tersebut sudah lama tidak dikembangkan lagi, maka dari itu saya ingin membuat model yang baru, banyak fiturnya dan bisa digunakan di seluruh devices.

Saya membuat aplikasi ini dengan AI dari Deepseek dengan bahasa pemograman HTML dan CSS supaya bisa dijalankan secara mudah. Selain itu bisa dijalankan secara online maupun offline.

Jelas sangat bisa. Aplikasi ini memang didesain secara offline sepenuhnya, tetapi untuk sementara hanya bisa diakses secara desktop seperti Windows, Linux maupun Mac OS karena lebih nyaman dipakai dan file aplikasi masih berbasis file HTML yang harus dibuka memakai browser. Untuk android saya sudah mencoba hasilnya masih kurang nyaman, kalau ada waktu saya buatkan versi aplikasinya. Untuk apple devices seperti iOS atau iPadOS dengan berat hati memakai versi online karena saya tidak bisa membuat aplikasi ke versi device tersebut.
